# WebSearcher Agent Example

## Overview

WebSearcher Agent is an intelligent agent component dedicated to web search. It automatically calls search engines based on user queries, crawls and parses web content, and extracts key information. The agent supports multi-round search and relevance ranking of results. It can also use natural language processing techniques to summarize and structure raw web pages, providing accurate, real-time web data support for higher-level applications such as question-answering systems, data analysis, and knowledge base construction.

## Usage Guide

Agent SDK provides an example for integrating WebSearcher Agent. For details, see the [WebSearcher Agent reference document](https://gitcode.com/Ascend/mindsdk-referenceapps/blob/master/AgentSDK/examples/agents/websearcher/README.md).
