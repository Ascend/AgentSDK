# Welcome to Agent SDK aura

<div style="text-align: center; margin: 0.5rem 0 0.3rem 0; font-family: 'Avenir Next', 'Avenir', 'Century Gothic', 'Segoe UI', sans-serif;">

Agent SDK aura helps you quickly train AI agents. It supports multiple trajectory generation methods and uses fused scheduling to efficiently use device memory. This docs repository provides guidance documents related to Agent SDK aura.
