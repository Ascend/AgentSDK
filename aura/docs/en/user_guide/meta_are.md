# Meta ARE Training Example

## Overview

ARE is an inference and execution framework proposed by Meta for agent scenarios. It uses the Gaia2 dataset. This example provides a template to help you quickly build and debug ARE agent training.

## Process

This section provides a simplified process. For the full execution flow, see [Meta-ARE](https://gitcode.com/Ascend/mindsdk-referenceapps/blob/master/AgentSDK/examples/meta-are).

1. Install Agent SDK.
   1. Obtain the software package.
   2. Install the SDK.
2. Install open-source software and set environment variables.
3. Run training and monitor metrics.
   1. Download the example code.
   2. Download the model weights and convert the weight format.
   3. Download the dataset and convert it.
   4. Adjust configuration parameters.
   5. Start the training task.
   6. Monitor runtime metrics.
